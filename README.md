# Heart Disease Prediction

A Machine Learning web application that predicts the possibility of heart disease based on patient health parameters.

## Live Demo

[Try the Live Demo](https://heart-disease-predictiongit-mrytzbyxnej4ljvruhhrmz.streamlit.app/)

## Tech Stack

- Python
- Scikit-learn
- KNN
- Pandas
- NumPy
- Streamlit

## Features

- Interactive prediction interface
- Machine Learning-based prediction
- Streamlit web application
- Easy-to-use interface
